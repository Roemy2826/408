## 计算机系统概述

### 计算机硬件
冯诺依曼计算机的特点：
1.采用**存储程序**的工作方式。
2.计算机硬件系统由**运算器** 、**存储器**、**控制器**、**输入设备**、**输出设备**组成。
3.指令和数据以同等地位存储在存储器中，形式上没有区别，但计算机可以区分。
4.指令和数据均为二进制代码表示。
5.指令由操作码和地址码组成，**操作码**指出操作的类型，**地址码**指出操作数的地址。

功能部件
1.输入设备
2.输出设备
3.存储器：分为主存储器和辅助存储器(外存)，其中 **主存储器** 包含 **MAR** (存储器地址寄存器) 和 **MDR**(存储器数据寄存器)
4.运算器：包含累加器(ACC)、乘商寄存器(MQ)、操作数寄存器(X)、变址寄存器(IX)、基址寄存器(BR)等
5.控制器：包含程序技术器(PC)、指令寄存器(IR)和控制单元(CU)


### 计算机软件

三个级别的语言
1.机器语言(二进制)
2.汇编语言(用英文单词/缩写代替二进制)
3.高级语言(C++/java/python)

三类翻译程序
1.汇编程序(将汇编语言程序翻译成机器语言程序)
2.解释程序(将源程序中的语句按顺序执行顺序逐条翻译成机器指令并立即执行)
3.编译程序(将高级语言程序翻译成汇编语言/机器语言)

指令集体系结构(ISA):软件与硬件之间的界面，定义了一台计算机可以执行的所有指令的集合。

### 计算机系统工作原理

翻译过程的四个阶段
1.预处理阶段
**.c** --> 预处理器(cpp) --> **.i**
2.编译阶段
**.i** --> 编译器(ccl) --> **.s**
3.汇编阶段
**.s** --> 汇编器(as) --> **.o**
4.链接阶段
**.o + printf.o** --> 链接器(ld) --> 可执行目标文件(二进制)
其中 **printf.o** 根据具体情况而改变，需要输出内容的程序就添加它。

取数指令的过程
1.取指令：**PC -> MAR -> M -> MDR -> IR**
2.分析指令：**OP(IR) -> CU**
3.执行指令：**Ad(IR) -> MAR -> M -> MDR -> ACC**


### 计算机的性能指标

**字长**：计算机进行一次整数运算所能处理的二进制数据的位数

**数据通路带宽**：数据总线一次所能并行传输数据的位数

**主存容量**：字数 X 字长

运算速度：
**吞吐量**(系统在单位时间内处理请求的数量),取决于主存储器的存取周期；
**响应时间**(指用户向计算机发送一个请求，到系统完成请求的时间),包括 CPU时间 和 等待时间；
**CPU时钟周期**(机器内部主时钟脉冲信号的宽度)，CPU工作的最小时间单位；
**主频** 时钟周期的倒数；**CPI** 执行一条指令所需的时钟周期的倒数；
**IPS** 每秒执行多少条指令， IPS = 主频/平均CPI；
**CPU执行时间** 运行一个程序所花费的时间， CPU执行时间 = CPU执行周期数/主频 = (指令条数 X CPI) / 主频。
**MIPS** (million Instructions Per Second)每秒执行多少百万条指令
**FLOPS** (Floating-point Operations Per Second) 每秒执行多少次浮点运算


**基准程序**：专门用来进行性能评价的一组程序
