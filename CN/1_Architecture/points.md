## 计算机网络体系结构

### 电路交换
>电路交换适用于低频次、连续且大量的数据传输

电路交换分为三个阶段：建立连接（占用通信资源）、传输数据（持续占用通信资源）、释放连接（归还通信资源）
**优点**
1.通信时延小
2.有序传输
3.没有冲突
4.实时性强
**缺点**
1.建立连接时间长
2.线路利用率低
3.灵活性差
4.难以实现差错控制

### 报文交换
流程：用户数据附加源地址、目的地址等控制信息后，被封装称报文（Message），报文交换采用存储转发技术：整个报文先传送到相邻节点，被完整接收并存储后，节点根据转发表将其转发至下一跳，如此逐条转发，直至到达目的端，每个报文可独立选择通往目的端的路径

**优点**
1.无建立和释放连接的时延
2.线路分配灵活
3.线路利用率高
4.支持差错控制
**缺点**
1.存储转发时延高
2.缓存开销大
3.错误处理低效

### 分组交换
>分组交换适用于突发式数据通信

流程：同样采用存储转发技术，但源主机在发送前，先将较长的报文划分成若干较小的等长数据段，并在每个数据段前面添加首部（必要控制信息:如源地址、目的地址、分组编号等），构成分组。
**优点**
1.继承了报文交换的诸多优点
2.便于存储管理
3.传输效率高
4.降低出错概率和重传代价
**缺点**
1.存在存储转发时延
2.需要传输额外的信息量
3.分组可能失序、丢失或重复

### 计算机网络的分类
按分布范围分类
1.广域网（几十到数千Km）
2.城域网（几个街区到整个城市：直径5-50Km）
3.局域网（几十到几千m）
4.个人局域网（个人工作或活动区域）

按传输技术分类
1.广播式网络
2.点对点网络

按拓扑结构分类
1.总线形网络
2.星形网络
3.环形网络
4.网状网络

按使用者分类：1.公用网 2.专用网

按传输介质分类：1.有线网络 2.无线网络

### 计算机网络的性能指标
>1.速率（Speed）

连接到网络上的节点在数字信道上传输数据的速率（也称数据传输速率、数据率或比特率）
在描述数据量时，K，M，G 通常用2的幂次表示，如 $1Kb = 2^{10}b$ ；在描述速率时，k，M，G 通常用10的幂次表示，如 $1kb/s = 10^3b/s$ 。通常数据量用大写K，速率用小写k，其他无论描述什么均为大写

>2.带宽（Bandwidth）

在计算机网络中，带宽表示网络通信线路所能传输数据的能力，指数字信道所能支持的最高数据传输速率；在通信领域，带宽通常是指通信线路允许通过的信号频率范围，单位是赫兹。

>3.吞吐量（Throughput）

在单位时间内通过某个网络的实际数据量

>4.时延（Delay）

指数据从网络的一端传送到另一端所需的总时间
$$总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延$$
发送时延(也称传输时延) = 分组长度/发送速率
传播时延 = 信道长度/电磁波在信道上的传播速率
处理时延 = 分组在交换节点为存储转发花费的时间
排队时延 = 分组在路由器的输入、输出队列花费的时间

>时延带宽积

时延带宽积 = 传播时延 X 信道带宽

>往返时延

指从发送端发出一个短分组，到收到接收端返回的确认信号所经历的总时间。
往返时延 = 发送端到接收端之间的往返传播时延 + 接收端的处理时延 + 中间节点的处理时延和排队时延

>信道利用率

信道利用率 = 有数据通过的时间/总时间


### 计算机网络分层
体系结构是抽象的，实现是具体的
**实体**指任何可发送或接受信息的硬件或软件进程
**对等层**：不同机器上的同一层 **对等实体**：同一层的实体互为对等实体

第 $n$ 层向第 $n+1$ 层提供的服务，是其本身和以下所有层所提供服务的总和

协议数据单元(PDU)：对等层之间传送的数据单位。第 $n$ 层的PDU记为 $n$ - PDU
服务数据单元(SDU)：相邻层之间交换的数据单位。第 $n$ 层的SDU记为 $n$ - SDU
协议控制信息(PCI)：用于控制协议操作的信息。第 $n$ 层的PCI记为 $n$ - PCI

$ PDU = SDU + PCI $

PDU(物理层)：比特流
PDU(数据链路层)：帧
PDU(网络层)：IP分组
PDU(传输层)：TCP报文段 或 UDP报文段
$ n-SDU + n-PCI = n-PDU = (n-1)-SDU $

**协议** 是控制对等实体之间通信的规则集合(不对等实体之间不存在协议)
协议 = 语法 + 语义 + 同步(或时序)
协议是水平的，服务是垂直的。

**服务访问点** 是同一节点内相邻两层实体交换信息的逻辑接口

**服务** 是指下层为紧邻的上层提供的功能调用

三种分类：
1(1).面向连接服务。 要求通信双方在传输前建立连接并分配资源(如缓冲区)。
全过程 = 连接建立 + 数据传输 + 连接释放
1(2).无连接服务。 无需预先建立连接，是不可靠服务。

2(1).可靠服务。 指网络具备检错、纠错和应答机制，能确保数据正确、完整、有序地送达目的地。
2(2).不可靠服务。 指网络仅提供 “ 尽最大努力交付 ”

3(1).有应答服务。 指在接收方在收到数据后，由传输系统自动向发送方返回应答。
3(2).无应答服务。 指接收方不自动返回应答。

### OSI参考模型
自下而上（1-7）：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。

**物理层(Physical Layer)**
传输单位：比特
功能：在物理介质上为数据端设备透明地传输原始比特流
作用：规定接口的机械特性和电气特性； 规定通信链路上的编码意义和电气特征(如约定信号X表示比特0)

传输用的物理介质不属于物理层，而是位于其下方（第0层）

**数据链路层(Data Link Layer)**
传输单位：帧
功能：将物理层提供的可能出错的物理连接，改造为逻辑上无差错的数据链路。将网络层交来的分组封装成帧，并可靠地传送到相邻节点的网络层，实现节点的差错控制与流量控制

在广播式网络的数据链路层中，还需要解决对共享信道的访问控制问题

**网络层(Network Layer)**
传输单位：数据报(或分组)
功能：将分组从源主机传送到目的主机，为不同主机提供通信服务
作用：路由选择，拥塞控制，差错控制，流量控制，网际互联等

网络层既提供有连接的虚电路服务，又提供无连接的数据报服务


**传输层(Transport Layer)**
功能：负责不同主机中进程之间的端到端通信，提供连接管理、可靠传输、流量控制、差错控制等服务

传输层需要具备复用与分用
1.复用：指多个应用程序可同时使用传输层的服务
2.分用：指传输层能将接收到的数据准确交付给对应的上层进程

**会话层(Session Layer)**
功能：管理不同主机上进程之间的会话，包括建立连接、维护和终止会话连接；为表示层或用户进程提供同步机制，支持在连接上有序地传输数据，并引入检查点功能(即当通信中断时，可从最近的检查点恢复会话)

**表示层(Presentation Layer)**
功能：解决异构系统间信息表示不一致的问题；数据压缩，加密与解密

**应用层(Application Layer)**
功能：作为用户与网络的接口

|层|功能|
|:--:|:--:|
|应用层|提供应用与网络接口|
|表示层|数据格式转换|
|会话层|会话管理|
|传输层|复用和分用、差错控制、流量控制、连接管理、可靠传输管理|
|网络层|路由选择、拥塞控制、网际互联、差错控制、流量控制、连接管理、可靠传输管理|
|数据链路层|差错控制、流量管理|
|物理层|定义电路接口参数、信号的含义/电气特征等|

### TCP/IP模型
从低到高：网络接口层、网际层、传输层、应用层

**网络接口层**
作用：(类似于OSI的物理层和数据链路层) 从主机或节点接收IP分组，并将其发送到指定的物理网络上。

**网际层**  (TCP/IP核心)
传输单位：IP数据报
功能：(类似于OSI的网络层) 负责将分组发往任意网络，并为每个分组独立选择路由，但不保证分组有序到达(有序性、可靠性由高层负责)
核心协议：网际协议IP，提供无连接，不可靠的服务


**传输层**
功能：(类似于OSI传输层) 实现发送端与接收端主机上对等进程之间的逻辑通信
协议：传输控制协议(Transmission Control Protocol,TCP)，面向连接，提供可靠交付，传输单位为报文段；用户数据报协议(User Datagram Protocol,UDP)，无连接，不保证可靠性，仅提供“尽最大努力交付”，传输单位为用户数据报

**应用层**
集成了OSI的中会话层、表示层和应用层的功能，包含所有高层协议

### TCP/IP与OSI的异同

**相似之处**
1.均采用分层体系结构，且各层功能大体相似
2.均基于独立协议栈的概念
3.均可解决异构网络互联问题，实现不同厂商生产的计算机之间的通信


**差异**
1.OSI最大的贡献在于精确定义了“服务”“协议”“接口”三个核心概念，而TCP/IP对这三者没有作出明确区分。
2.OSI是7层；TCP/IP为4层。
TCP/IP将OSI的 “ 表示层、会话层、应用层 ” 合并为 “ 应用层 ” ，将 “ 数据链路层、物理层 ” 合并为 “ 网络接口层 ”。
3.OSI先有模型，后制定具体协议，通用性良好，适合描述各类网络；TCP/IP先有协议栈，后归纳出模型，不适用于任何其他非TCP/IP模型
4.OSI在网络层同时支持无连接和面向连接的通信模式，但在传输层仅提供面向连接的服务；TCP/IP在网际层仅提供无连接服务，但在传输层同时支持无连接和面向连接。
